# 策略综合评分：0.5.0

每次比较同一只股票、同一数据区间和相同执行参数下的策略预设。本次采用三项指标：年化收益、最大回撤、夏普比率。三者也是 QuantConnect 文档列出的 [策略优化目标](https://www.quantconnect.com/docs/v2/cloud-platform/optimization/objectives)；这里的权重与百分位加权方法由本项目定义，并非该平台或行业的统一评分标准。

## 分项与权重

| 指标 | 权重 | 得分方向 | 本项目原始口径 |
| --- | ---: | --- | --- |
| 年化收益 | 30% | 越大越好 | 根据首末资金比例和实际日历年数计算 CAGR，含费用和滑点 |
| 最大回撤 | 30% | 越小越好 | 收盘净值从此前峰值的最大跌幅，含期末平仓成本 |
| 夏普比率 | 40% | 越大越好 | 相邻日线净值简单收益的均值 / 总体标准差 × √252，无风险收益率为0 |

总收益与年化收益在本次相同区间内排序相同，因此只计年化收益一次。胜率、盈利因子、交易笔数仍展示，但不参与主评分：单靠胜率不能反映盈亏金额，盈利因子在没有亏损交易时不定义，交易笔数少也不等于长期持有策略必然较差。

权重在查看评分结果之前确定，没有为抬高某个策略名次而调节。三项指标并非完全独立，评分只是一种明确、可复现的比较偏好，不代表统计最优。

## 0–100分的计算

对本批符合条件的 N 组预设，逐指标做百分位打分。设：

- W 为该项指标严格劣于当前策略的预设数；
- E 为与当前策略该项指标完全相等的预设数，包含自身；
- N 为本批有效预设总数。

当 N>1 时：

```text
分项分 = 100 × [W + (E − 1) / 2] / (N − 1)
综合分 = 年化收益分 × 0.30 + 回撤分 × 0.30 + 夏普分 × 0.40
```

例如3组策略，某项无并列且从差到好排列时，分项分为0、50、100。如果两组并列最好、一组较差，两组最好均为75。所有策略该项都相同时均为50；只有1组有效预设时，三个分项及综合分均为50。

百分位法以顺序为依据，极端指标数值不会挤压其他预设的分数，但也不表达数值差距的大小。10%和11%与10%和100%在只有两组预设时都会分别获得0和100分。因此必须同时查看原始指标。增加、移除预设也会改变相对分数。

每组参数单独算一行，不按策略类别合并。原0.5.0的36组排名包含SMA三组和RSI两组；0.6.0按原评分删除低于 Buy & Hold 的16组预设后，当前评分集合为20组，包含SMA两组和RSI一组。相近策略和参数可能相关，不能将预设数视为独立统计样本数。名单详见 [筛选记录](preset-selection.md)。

## 排序、缺失值与交易笔数

- 综合分降序。按完整浮点精度排序，展示保留两位小数；显示相同不一定是精确并列。
- 同分共享名次，采用1、1、3的竞赛排名，同分行保留输入顺序。先以整数计算各项平均名次的两倍值，按30/30/40加权后统一除以分母，避免逐项浮点运算把数学同分拆成不同名次。
- 完全无已平仓交易且无期末持仓：`status=no_trades`，分数与名次为null，不纳入百分位分母；避免无成交策略仅靠零回撤获得高分。
- 年化收益缺失、区间不足一天、夏普或回撤非有限数、回撤不在0–100范围：`status=missing_metrics`，同样不参与评分。负收益、负夏普本身是有效值，仍可参与比较。
- 未评分行放在末尾，JSON用null、CSV留空、表格显示N/A；N/A不是0分。
- 少于5笔已平仓交易：`few_closed_trades=true`，表格交易数后标星，不改变分数。5笔是展示提醒的约定阈值，不是“统计可信”的分界线，也不保证超过5笔就可靠。
- 有期末未平仓持仓仍可按净值指标评分，`open_position=true` 保留；此时最终净值尚未扣除未来卖出成本。

库函数会拒绝日期序列、区间、初始资金、价格模式、费用、滑点或整手设置不同的结果混排。结果结构不含股票代码，库调用者须自行确保同一标的和相同行情；CLI一次只读一个标的。

## 命令与导出

```powershell
.\scripts\cargo.ps1 build --locked --release
.\target\release\financial_projects.exe compare --symbol 0700 --data-dir data/tencent-5y --rank
.\target\release\financial_projects.exe compare --symbol 0700 --data-dir data/tencent-5y --rank --format json --output reports/tencent-ranking-20.json
.\target\release\financial_projects.exe compare --symbol 0700 --data-dir data/tencent-5y --rank --format csv --output reports/tencent-ranking-20.csv
```

JSON保留原有参数、统计、交易明细与净值曲线，并新增 `ranking` 对象。CSV包含名次、总分、三项原始指标及分项分、总收益、胜率、交易数、盈利因子、评分状态、权重JSON、来源参数JSON和执行设置。表格在每条策略下显示分项分和参数，便于区分同名策略的不同预设。

版本标识为 `percentile_30_return_30_drawdown_40_sharpe_v1`。固定权重导出为 `annual_return=0.30, drawdown=0.30, sharpe=0.40`。库接口为 `financial_projects::backtest::ranking::rank_results(&results)`，只借用原始结果，不更改任何回测值。

## 解释范围

这份分数用于历史结果的相对比较，不是未来收益预测、盈利概率或投资评级。即使所有策略亏损，其中仍可能有相对高分。腾讯的分数不能直接与其他股票、其他时间段、其他预设集合的分数比较。

原回测包含各策略不同长度的预热等待；没有做共同起点截断、样本外走步检验、参数稳定性检验或多重试验校正。默认复权合成价格、小数份额及港股费用近似沿用 [README](../README.md) 的限制。
